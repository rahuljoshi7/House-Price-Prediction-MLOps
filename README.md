# House Price Prediction – MLOps Project

## Overview
This project demonstrates a structured MLOps workflow for predicting house prices using Machine Learning.

## Objectives
- Build a house price prediction model.
- Maintain version control using Git.
- Follow a structured branching strategy.
- Document the MLOps lifecycle.
- Test the machine learning model.

## Technologies
- Python
- Scikit-learn
- Pandas
- NumPy
- Git and GitHub
- Pytest

## Project Structure
- data: Dataset files
- src: Source code
- tests: Unit tests
- models: Saved machine learning models
- notebooks: Experiment notebooks
- .github/workflows: GitHub Actions workflows
